1. System Requirements

  • PHP Version: PHP 8.2 or PHP 8.3 (Recommended)
  • Database: MySQL 5.7+ or MariaDB 10.3+
  • Web Server: Apache (with mod_rewrite enabled) or Nginx
  • Required PHP Extensions: BCMath, Ctype, cURL, DOM, Fileinfo, JSON, Mbstring, OpenSSL, PCRE, PDO, pdo_mysql, Tokenizer, XML
  • Writable Directories: storage/ and bootstrap/cache/

2. Quick 3-Step Layman Web Installation

1Upload Code to Your Web Server

  • Extract the downloaded .zip package on your computer.
  • Upload all files into your web hosting directory (e.g. public_html in cPanel, or /var/www/html, or XAMPP htdocs/realestate).
  • Make sure your domain or web server points to the project root (where index.php is located) or public/.

2Launch the 2-Minute Web Installer

  • Open your browser and visit your website URL:
    https://your-domain.com/
  • The system will automatically redirect you to the Layman Web Installer:
    https://your-domain.com/install

3Fill Step 1: Customer Details & Purchase Code

  • Name: Your Full Name.
  • Phone: Select your country code from the dropdown (e.g. 🇮🇳 +91 India, 🇺🇸 +1 US, 🇦🇪 +971 UAE) and enter your mobile number.
  • Email: Your active email address.
  • Purchase Code: Enter the official purchase code provided in your download package or Webotapp Lab Dashboard (e.g. WEBOT-REAL-XXXX-XXXX-XXXX).
  • Click "Verify Code & Continue".

4Fill Step 2: Database Credentials

  • Database Host: 127.0.0.1 (or localhost)
  • Database Port: 3306
  • Database Name: Name of your database (e.g. realestate). If it doesn't exist, the wizard will auto-create it!
  • Database Username: Your MySQL username (e.g. root or your cPanel db user)
  • Database Password: Your MySQL password
  • Click "Test Connection" to verify, then click "Start Installation & Migrate".
